Como utilizar o arquivo de modelo.
1. Salvar o arquivo de modelo modelo-style-portal-educacional.css, na pasta do projeto como style.css.
2. Vincular o CSS ao documento HTML:
<link rel="stylesheet" href="style.css">


3. Utilizar as classes disponibilizadas, por exemplo:
<main class="container main-content">
  <section class="card">
    <h1 class="card-title">Meu projeto</h1>
    <p class="card-description">
      Descrição do sistema desenvolvido.
    </p>
    <a class="button" href="#conteudo">Acessar conteúdo</a>
  </section>
</main>


4. Personalizar as variáveis de :root para definir as cores e a identidade visual do projeto.
