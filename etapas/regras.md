Regras
- As imagens utilizadas devem ser de banco de imagens gratuítos.
- O projeto deve possuir os arquivos necessários para o funcionamento e regras de instalação.
- O layout deve possuir elementos (logotipo, fontes, cores) e devem ser especificados na documentação.
- Cada conteúdo deve ter uma página individual.
- O projeto deve ter um repositório no github (portal-educativo).
- O arquivo README.md deve explicar os objetivos do projeto e a forma de instalação.
- O projeto deve possuir arquivos separados para html, css e javascript.
- O relatório do projeto deve conter as referências completas dos recursos e arquivos utilizados.
- A utilização de ferramentas de IA é para auxiliar em dúvidas e não para a implementação completa do portal.
